Windows Desktop

Windows Installation

  1. Download and run the installer (thoughtholder-setup-1.4.1.exe).
  2. Follow the setup wizard to install Thoughtholder. (If Windows SmartScreen prompts, click More info → Run anyway).
  3. Press Ctrl + Shift + B from anywhere in Windows to summon instant capture.
  4. Thoughtholder stays ready in your System Tray and starts when you log in.
Android Mobile

Android Installation

  1. Open the downloaded thoughtholder-1.4.1.apk. If Android asks, allow installs from your browser.
  2. Tap Install (choose More details → Install anyway if Play Protect prompts).
  3. Open Thoughtholder, allow microphone, and tap to record.
